# ThermoFlow Engineering Dashboard

[Open the Live ThermoFlow App](https://thermoflow-engineering-dashboard.streamlit.app/)

## Project Description

ThermoFlow is an interactive Streamlit engineering application developed for petroleum engineering thermodynamics analysis. The application uses the Peng-Robinson Equation of State (EOS) to estimate real-gas properties including compressibility factor, fugacity coefficient, fugacity, and gas density. Users can select different gases and interactively change temperature, pressure, pressure range, and analysis points through the sidebar. The application also provides interactive Plotly visualizations, a Pandas results table, engineering interpretation, and input/error handling.

## Features

- Peng-Robinson Equation of State
- Real-gas compressibility factor (Z)
- Fugacity coefficient
- Fugacity
- Real-gas density
- Interactive pressure analysis
- Plotly visualization
- Pandas results table
- Multiple gas options
- Engineering interpretation
- Input validation and error handling

## Technologies Used

## How to Use

1. Select a gas from the sidebar.
2. Enter the operating temperature.
3. Enter the operating pressure.
4. Select the pressure range for analysis.
5. Review the calculated thermodynamic properties.
6. Examine the interactive graphs and results table.

ChatGPT was used as an AI-assisted development tool for application planning, Python/Streamlit code generation, debugging assistance, and engineering logic review. AI-generated code was manually reviewed, tested, and verified using known Peng-Robinson calculations and engineering reasoning.
